## Correctness and focused fixes

Oxford trimap labels map 1 -> pet, 2 -> background, 3 -> ignored 255. Paired geometry and EXIF orientation preserve alignment; masks use nearest-neighbor resizing. Evaluation resizes logits before argmax and accumulates one confusion matrix across original-resolution valid pixels. Ignored outlines do not contribute to reported quality. This is binary semantic segmentation and replacement, not instance segmentation or alpha matting.

Content-grouped splits check exact decoded duplicates across partitions, not all near-duplicates or pretraining overlap. A/B/C initialize independently from the same seeded ImageNet-backbone/new-head state. A also freezes backbone BatchNorm statistics.

The review fixed interrupted completion recovery, run/checkpoint identity, deployment consistency, timing order, stale report evidence, Colab persistence, portable JSON and source packaging. `inspect_run` checks config, manifest, training IDs, histories, environment, checkpoint hashes and stopping state before reuse. Selection verifies common initial tensor fingerprints and comparable budgets. CPU timing interleaves all six resolution/path combinations. App/default CLI/final evaluation bind the measured decision to the model and split.

Checkpoint and checksum files are separate replacements: interruption between them is detected and rejected. This is not a multi-file transaction or power-loss guarantee. Exact training equality across devices and library versions is not promised.
